# 🎓 ПББ Информатика — Ресми Тест Симуляторы 2026

Педагогтердің білімін бағалауға (ПББ / ОЗП) және ҰБТ-ға дайындалуға арналған заманауи веб-платформа.

---

## 🌟 Басты мүмкіндіктері

- **1 054+ Сұрақтан тұратын ауқымды база:** Ресми жинақтар, соңғы емтихан сливтері мен нақты тест нұсқалары толық енгізілген.
- **Ресми спецификацияға 100% сәйкестік:** Әрбір тест нұсқасы бекітілген 12 тақырып бойынша дәл **50 сұрақ (50 ұпай)** көлемінде автоматты түрде генерацияланады:
  1. Ақпаратты ұсыну және өлшеу. Ақпараттық процестер — 5 сұрақ
  2. Компьютерлік жүйелер — 4 сұрақ
  3. Логикалық операциялар — 2 сұрақ
  4. Компьютерлік желілер және қауіпсіздік — 6 сұрақ
  5. Компьютерлік графика — 2 сұрақ
  6. Есептерді электронды кестелердің көмегімен шешу, өңдеу (Excel) — 4 сұрақ
  7. Мәліметтер қорымен жұмыс (SQL) — 4 сұрақ
  8. Программаларды құрудың кіріктірілген орталары (Python) — 7 сұрақ
  9. Вебжобалау (HTML/CSS) — 4 сұрақ
  10. Мәтіндік құжатпен жұмыс. Бейнеконтент — 1 сұрақ
  11. Жасанды интеллект (AI) — 1 сұрақ
  12. Мәнмәтіндік тапсырмалар (Контекст) — 10 сұрақ
- **Нағыз емтихан симуляторы:** 100 минуттық кері санақ таймері, 1-ден 50-ге дейінгі интерактивті сұрақтар картасы (Grid Matrix), күмәнді сұрақтарды белгілеу (Review later).
- **Толық талдау және қатемен жұмыс:**
  - Санатты автоматты анықтау (*Педагог-Модератор, Сарапшы, Зерттеуші, Шебер*);
  - 12 тақырып бойынша жеке прогресс-барлар;
  - Әрбір сұрақтың дұрыс жауабы мен қазақ тіліндегі толық түсіндірмесі;
  - Нәтижені басып шығару (Print / PDF).
- **Сұрақтар қоры және басқару:** Жаңа сұрақтар қосу, іздеу, сүзу, JSON форматында экспорттау және импорттау.
- **Дербестік:** Барлық мәліметтер браузердің `Local Storage` жадында сақталады, интернетсіз де автономды жұмыс істей алады.

## 🚀 Компьютерде іске қосу

1. `ІСКЕ_ҚОСУ.bat` файлын екі рет басыңыз.
2. Немесе браузер арқылы `index.html` файлын тікелей ашыңыз.
3. Немесе Python арқылы:
   ```bash
   python run_app.py
   ```

## 🌐 GitHub Pages арқылы онлайн жариялау

Бұл сайтты интернетте баршаға ашық ету үшін **GitHub Pages** тегін қызметін қосуға болады:
1. GitHub-та осы репозиторийдің **Settings** бөліміне өтіңіз.
2. Сол жақ мәзірден **Pages** бөлімін таңдаңыз.
3. **Branch** бөлімінен `main` тармағын және `/ (root)` папкасын таңдап, **Save** батырмасын басыңыз.
4. 1-2 минуттан кейін сайтыңыз `https://<сіздің-логиніңіз>.github.io/<репозиторий-атауы>/` сілтемесі бойынша онлайн қолжетімді болады!
